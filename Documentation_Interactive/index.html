Le Cahier des Charges

Notre Objectif

Développer une plateforme web permettant de mettre en relation les étudiants de l'IFRI pour du mentorat (académique et professionnel).

Contraintes

Nous avons 10 jours pour réaliser une application fonctionnelle en équipe de 5 à 6 étudiants, en utilisant des technologies modernes.

Fonctionnalités Clés

  • Gestion de profils (points forts / lacunes).
  • Dépôt d'offres et de demandes.
  • Algorithme de Matching (compatibilité).
  • Messagerie interne.

Nos Technologies Expliquées

Git : La machine à remonter le temps

Git enregistre les modifications de notre code. Imaginez que c'est un jeu vidéo avec des points de sauvegarde.


Commit
Une sauvegarde de votre code local.

Branche
Un espace isolé (votre brouillon personnel).

Push / Merge
Envoi sur GitHub et fusion avec le projet final.

Règle d'or : On ne travaille jamais sur `principale`. On crée toujours une branche `feature/...` !

Django : Le moteur de la voiture

Django est un Framework Python. Il gère la sécurité, les mots de passe, et lie la base de données au site web.

M - Modèle (`models.py`)

La structure des données (Tables SQL).

V - Vue (`views.py`)

La logique : qui demande quoi et comment on traite l'info.

T - Template (`templates/`)

L'affichage final : le HTML/CSS que voit l'utilisateur.

MySQL : La mémoire du projet

Nous stockons les informations dans des "Tableaux" reliés entre eux. Voici notre architecture simplifiée :

Utilisateur
- ID
- Email
- Mot de passe
Profil
- Bio
- Filière
- Photo
Compétence
- Point fort
- Lacune

Visite Guidée du Projet

Le projet est 100% en français (dossiers et variables) sauf les fichiers techniques de Django (pour ne pas casser le framework).

  • 📁 PIL1_2526_69 (Le dossier racine)
    • 📁 projet_mentorlink (Configuration globale)
      • 📄 `settings.py` (Où l'on configure MySQL)
    • 📁 application_principale (Là où on code)
      • 📄 `models.py` (Où sont créées nos tables SQL)
      • 📄 `views.py` (Où l'on gère l'inscription, connexion, etc.)
      • 📄 `utils.py` (Où se trouve notre super algorithme de matching)
      • 📁 templates (Où les frontend mettent leur HTML)
    • 📁 Taches_Equipe (Les missions de chaque membre)

Foire Aux Questions (F.A.Q)

Ouvrez votre terminal et tapez : git clone https://github.com/Gynias/PIL1_2526_69.git

Allez dans le dossier Taches_Equipe, ouvrez votre dossier personnel (Membre 4 ou 5) et vous trouverez un dossier maquettes prêt à l'emploi.

Dans le terminal, tapez python manage.py runserver. Allez ensuite sur votre navigateur à l'adresse http://localhost:8000.

Pas de panique ! C'est l'avantage de Git. Si vous n'avez pas encore fait de "commit", vous pouvez annuler avec git restore .. Sinon, contactez le Chef de Projet !
