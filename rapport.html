2. Conception et Architecture

Architecture Logicielle

L'application repose sur une architecture Client-Serveur suivant le motif architectural MVT (Modèle-Vue-Template) du framework Python Django :

  • Frontend (Client) : HTML5, CSS3 avec des utilitaires Tailwind, JavaScript Vanilla (pour la messagerie temps réel).
  • Backend (Serveur) : Django (Python 3.10+).
  • Base de Données : Configuré par défaut sur SQLite pour les tests, mais entièrement modélisé via l'ORM Django, ce qui le rend 100% compatible avec MySQL ou PostgreSQL en production. Le fichier structure_bdd.sql inclus montre l'architecture des tables.

Structure de la Base de Données

Les modèles principaux sont :

  • Utilisateur : Étend le modèle de base Django avec filière, rôle (mentor, mentoré), photo, etc.
  • Competence : Les matières de l'IFRI (ex: Python, Mathématiques).
  • DemandeOuOffre : Les annonces publiées, avec format (ligne/présentiel) et horaires.
  • Conversation & Message : Gère les échanges de texte entre deux utilisateurs.
  • Notification : Alertes pour les nouveaux messages et annonces.

3. Instructions de Déploiement

Note Technique : Le projet est livré "prêt à l'emploi".

  1. Cloner le dépôt : git clone https://github.com/Gynias/PIL1_2526_69.git
  2. Créer un environnement virtuel : python -m venv venv puis l'activer (venv\Scripts\activate sous Windows).
  3. Installer les dépendances : pip install -r requirements.txt
  4. Initialiser la base de données : python manage.py migrate
  5. Peupler les compétences par défaut : python manage.py seed_competences
  6. Lancer le serveur : python manage.py runserver
  7. Accéder à http://127.0.0.1:8000/

Pour passer en environnement de production, modifiez ALLOWED_HOSTS dans settings.py et passez DEBUG = False. Branchez un SGBD MySQL dans la section DATABASES.

4. Manuel d'Utilisation

Pour un Nouvel Utilisateur

  • Étape 1 : Rendez-vous sur la page d'inscription et créez un compte (Rôle Mentor, Mentoré ou les deux).
  • Étape 2 : Passez par l'Onboarding interactif pour renseigner vos "Points forts" (si vous êtes mentor) et "Lacunes" (si mentoré).
  • Étape 3 : Accédez au Dashboard. Si vous cherchez de l'aide, l'algorithme vous proposera automatiquement dans la section "Mentors Recommandés" les profils compatibles avec vos lacunes.
  • Étape 4 : Cliquez sur "Contacter" pour ouvrir la messagerie instantanée intégrée.
  • Étape 5 : Vous pouvez également publier une Annonce globale depuis l'interface "Annonces", ou répondre à celles des autres.
