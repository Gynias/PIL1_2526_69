# Fiche de Mission : Membre 2 (Backend)
## Thème : Authentification et Profil Utilisateur

Bienvenue ! En tant que développeur backend, ton rôle est de donner vie à la base de données. 
Le chef de projet a déjà configuré la base de données (`models.py`).

### Tes missions :
1. **Créer ta branche de travail** : `git checkout -b feature/authentification` (à partir de `developpement`).
2. **Inscription (Sign up)** : Dans `views.py`, crée une vue qui permet à un nouvel étudiant de créer son compte (modèle `Utilisateur`).
3. **Connexion / Déconnexion (Login/Logout)** : Utilise les fonctions natives de Django (`django.contrib.auth`) pour connecter les utilisateurs.
4. **Gestion du Profil** : Crée une vue qui permet à l'utilisateur de remplir son `Profil` (bio, centres d'intérêt, etc.) et ses `CompetenceUtilisateur` (points forts / points faibles).
5. **Soumission (Pull Request)** : Quand tout fonctionne, pousse ta branche et demande la fusion vers `developpement`.
