# Fiche de Mission : Membre 5 (Frontend)
## Thème : Intégration Visuelle (Tableau de bord, Matching, Messagerie)

Bienvenue ! Ton rôle est d'intégrer les pages principales de l'application dans Django.
Le chef de projet t'a fourni les fichiers HTML/CSS dans le dossier `maquettes/` (juste à côté de ce fichier).

### Tes missions :
1. **Créer ta branche de travail** : `git checkout -b feature/integration-dashboard` (à partir de `developpement`).
2. **Dossier Templates** : Tes fichiers iront dans le dossier `application_principale/templates/`.
3. **Intégration du Dashboard** : Adapte le fichier `dashboard_desktop.html` pour qu'il affiche dynamiquement les données envoyées par le Backend.
4. **Intégration du Matching** : Transforme la page `matching_page.html` pour qu'elle puisse afficher la liste des "5 meilleurs matchs" générés par l'algorithme du chef de projet.
5. **Intégration Messagerie** : Adapte les pages `conversations_list_desktop` et `open_conversation_desktop`.
6. **Soumission (Pull Request)** : Pousse ton travail vers `developpement`.
